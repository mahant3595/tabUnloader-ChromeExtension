TabUnloader

Smart Tab & Memory Manager — settings are saved locally and restored after restarts.

Inactivity timeout

Changes apply immediately — no restart needed. Shorter timeouts are checked by the 30-second scheduler, so actual unloading can lag the setting by up to ~30 seconds. Manual controls (popup) keep working even when automatic unloading is off.

Startup protection, session restoration & tab groups

Known Chrome API limitations for startup protection
  • Chrome begins loading session-restored pages before an extension service worker can run, and no supported API (tabs, webNavigation, sessions, declarativeNetRequest) can pause or cancel those first requests. TabUnloader therefore discards restored tabs as early as the APIs permit — this reduces memory usage but cannot guarantee zero initial network requests.
  • chrome.tabs.discard() refuses to discard the tab that is currently in focus. With "Load active tab automatically on startup" OFF, the initially selected tab is discarded at the first opportunity after you switch away from it.
  • Chrome may lazy-load restored tabs over time; whenever a restored tab starts loading in the background, TabUnloader discards it (up to 3 attempts per tab).
  • Chrome eagerly loads every tab inside a tab group when you open the group — there is no Chrome setting to stop this. With the group load guard ON (default), TabUnloader immediately unloads the background members again after Chrome loads them: the tab you are viewing stays loaded, and tabs you deliberately opened yourself (e.g. middle-click) are left alone. Note this does not prevent the brief load itself, only keeps it from using memory afterwards.
  • Tabs that are active in their own window (including background windows) cannot be discarded by Chrome while that window exists.

Protection rules

"Keep This Tab Loaded" protects the tab…

Chrome cannot reliably detect unsaved form data, active video calls, or background work, so those situations are protected only when they surface as pinned/audio tabs or through rules you add here. The active tab is never unloaded automatically.

Website exclusions

Tabs on these sites are never unloaded automatically (startup protection also skips them). Excluded tabs are never loaded automatically either — exclusion only prevents unloading.

    Pattern meaning: mail.google.com matches exactly that host; *.example.com matches example.com and all of its subdomains; a leading scheme (https://) or a port is allowed and ignored; paths are rejected.

    Appearance

    Dashboard

    Chrome does not expose reliable per-tab memory usage to extensions. The estimate is a simple multiplication you configure — it is not a measurement. For real numbers, open Chrome's built-in Task Manager (Menu → More tools → Task Manager).

    Privacy

    • TabUnloader runs entirely locally. No account, no servers.
    • No browsing history, URLs, or page contents ever leave your browser.
    • No analytics, tracking, or advertisements; no third-party dependencies.
    • Permissions used: tabs (inspect tab state and discard tabs), storage (settings), alarms (scheduled sweeps). No website access permissions are requested.
    • Warning: discarding a tab frees memory but discards the page's JavaScript state — unsaved form input or in-progress work on that page may be lost when it reloads.

    Reset

    Restore all settings to their defaults (5-minute timeout, startup protection on).

    TabUnloader never closes tabs. It only discards pages with Chrome's supported API, and tabs reload when you activate them again.
